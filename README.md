# Agency Nexus: The Ultimate Agency OS for WordPress

Agency Nexus is a comprehensive "Agency Operating System" that integrates project management, content operations, client collaboration, and financial intelligence into a single, white-labeled WordPress dashboard.

## 🚀 Core Features
*   **SmartOnboard:** Interactive scope builder with dynamic budget calculators.
*   **ContentMatrix:** Pillar content architecture and drag-and-drop scheduling.
*   **ApprovalFlow:** Multi-stage draft system with side-by-side comparison.
*   **EngageTrack:** Intelligent lead capture with sentiment analysis and embed codes.
*   **MoneyFlow:** Real-time project profitability (ROI) and branded invoicing.
*   **ClientSync:** Secure, real-time messaging hub and file sharing.
*   **AutoPilot:** Custom "If-This-Then-That" automation engine.
*   **BurnoutGuard:** Team workload monitoring and stress check-ins.

## 🛠 Advanced Task Management
Agency Nexus provides granular control over your agency's execution:
*   **Detailed Instructions:** Add specific briefs or descriptions to every task.
*   **Time Log Management:** View, edit, or delete individual hours entries to ensure financial accuracy.
*   **Project Leads:** Assign specific team members to lead projects and manage dependencies.

## 📦 Installation
1.  Upload the `agency-nexus` folder to your `/wp-content/plugins/` directory.
2.  Activate the plugin through the 'Plugins' menu in WordPress.
3.  Navigate to the 'Agency Nexus' menu to begin your calibration journey.
